# GPX Viewer

Interactive GPX file viewer with a topo map and synced elevation profile.

## Usage

1. Open `GPX Viewer.html` in your browser
2. Drag and drop a `.gpx` file onto the page

No installs, no server, no dependencies — just one HTML file.

## Features

- **Topo map** (OpenTopoMap) with route overlay
- **Elevation profile** synced to the map — hover to see your position
- **Time info** on hover: local time of day and elapsed time since start
- **Selection**: click and drag on the profile to highlight a section and see distance, elevation gain/loss
- **Resizable**: drag the handle between map and profile to adjust the split
- **Drag and drop**: load any `.gpx` file directly in the browser
